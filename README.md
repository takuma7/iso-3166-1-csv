# iso-3166-1-csv

Development and country-data updates have moved to
[`takuma7/iso-3166-1-ts`](https://github.com/takuma7/iso-3166-1-ts).

- [Canonical CSV](https://github.com/takuma7/iso-3166-1-ts/blob/main/data/iso-3166-1.csv)
- [Raw CSV](https://raw.githubusercontent.com/takuma7/iso-3166-1-ts/main/data/iso-3166-1.csv)
- [Scraper and update workflow](https://github.com/takuma7/iso-3166-1-ts#update-country-data)

The CSV contains ISO 3166-1 Alpha-2, Alpha-3, and numeric codes with English and
French short names extracted from ISO's website.

This repository retains its existing file and Git history. Its raw CSV URL
continues to serve a historical snapshot; use the canonical location for future
updates, or pin a commit when reproducible data is required. Please open new
issues and pull requests in the canonical repository.
